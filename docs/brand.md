# Brand mark

`application/public/logo.svg` is the master of the OpenGameInstaller mark; `application/public/logo-mono.svg` is the single-colour variant (it uses `currentColor`) for trays, lists and other places one colour is all there is. Every raster logo in this repository — `application/public/favicon*.png`, the `favicon.ico` files, `updater/public/favicon*`, `web/public/favicon.png`, the root `favicon.*` — is an export of the master. Change the SVG and re-export; do not hand-edit the rasters.

The mark is original work contributed under the repository's AGPL-3.0-only licence. It uses the app's dark-theme palette (`#0f172a`/`#1e293b` tile, `#5ee7e0` glyph) so it sits with the themes without depending on them. Keep the "OpenGameInstaller" wordmark as plain text next to it.
